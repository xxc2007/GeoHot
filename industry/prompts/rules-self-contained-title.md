
【标题自洽规则 — 让读者不点开就知道"这是关于哪儿的什么事"】

1. 标题必须点出核心主体：地点 / 机构名 / 台网与卫星任务名 / 数据产品与规划名 / 项目名。地理事件按"地点 + 现象 + 量级或影响"组织，量级带单位（7.2 级、14 级风力、超警 0.5 米、3200 平方公里）。地点写到原文支持的最小一级（县 / 市 / 流域 / 海域方位），不越级猜测、不把"近海"改成某个省。整标题控制在 30 字内，不用"引关注""自然之力""重磅"等空话。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。机构缩写与卫星、数据产品名（USGS、NOAA、Sentinel-2、Copernicus、MODIS、DEM）按原样保留。
3. 原标题只是参数 / 代号 / 没信息量的 teaser（如 "M4.2"、"Weekly update"、"New map"、"本周影像"、"速报"）时，结合【来源】和正文把主体补进标题。例：原标题 "M4.2" + 来源 "中国地震台网中心：速报" + 正文明确写了四川宜宾兴文县 → "四川宜宾兴文县发生4.2级地震"（正文没给地点时按第 4 条兜底，不要自己补县名）。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体地点、台网口径或量级时，用上位词兜底（如"西南某流域"、"一次近海地震"、"一组卫星影像"），绝不凭"地理常识"编一个县名、经纬度、震级、面积或伤亡数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Comparison 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文用到了一份新影像、一个新数据集或一处已经存在的灾害，就改写成"发布 / 首次观测到 / 发现 / 证实"。只有原标题明确宣布了发布、公布、首次观测或发现，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、地区、项目名。
   例：原标题 "How Sentinel-1 sees through flood clouds" → "哨兵一号如何穿过云雨观测洪水"，不能写成 "ESA 发布哨兵一号卫星"。
   例：原标题 "Terrain analysis of the 2024 landslide deposit" + 来源和正文明确是某学院团队 → "某学院团队分析 2024 年滑坡堆积体地形"，不能写成"首次发现滑坡"，也不能只留缺主体的"滑坡地形分析"。
6. 影响与结论未定时不要写成定论：原文只说"未收到伤亡报告"就写"暂无人员伤亡报告"或"官方尚未通报伤亡情况"，不要写成"无损"或"损失惨重"；预警是否解除、数据是否开放、数字是否为初步值，都按原文口径进标题。例："印尼苏门答腊近海发生7.2级地震，暂无人员伤亡报告"。
