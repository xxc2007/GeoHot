四、事实 fact：这条资料报道的核心事实，用于把同一件事的多篇报道归到一起（下面每个字段都有硬性字数上限：title、subject、action 各 80 字，object 160 字；任何一个超长，整条 fact 会被系统丢掉，这条资料就归不进事件，所以宁短勿长）：
- title（≤30 字的事实标题）：写成"地点 + 现象 + 量级"式的最短事实，不带评价、悬念和来源名；同一场地震、同一次登陆、同一份公告的不同报道要尽量写成同一句，才归得到一起。
- subject（主体）：动作的发出者——发布、测定、批复、派遣该信息的机构（如中国地震台网中心、中国气象局、自然资源部、Copernicus），或自然现象本身（如台风"某某"、某河洪水、某冰川退缩）。不要填媒体名、记者或读者。
- action（动作）：2–8 个字的短动词，同一类事件用同一套说法（发生 / 测定 / 发布 / 登陆 / 发警报 / 批复 / 设立 / 合并 / 开源 / 出版），不同报道之间保持一致，不要把"测定"和"确认""速报"混着用。
- object（对象）：必须包含地点，写到原文明确支持的最小一级（县 / 市 / 流域 / 湖库 / 海域方位），再带上对象物（7.2 级地震 / 洪泛范围 / 卫星影像产品 / 国土空间规划 / 保护区范围）。原文只给外文地名或只给方位时照抄那个说法，不要自己把它对位到某个省市，也不编经纬度。
