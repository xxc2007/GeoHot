
【防幻觉规则 — 严格遵守】

1. 严禁添加原文未明确提到的地点 / 数字 / 单位 / 时间 / 量级 / 范围 / 机构口径 / 数据集名称
2. 不确定的细节宁可省略，也不要"听起来合理地补全"
3. 原文里某个地名、专业词或你不理解的表述，原文照抄关键词，不要"翻译性发挥"
4. 摘要里出现的每一个地名 / 机构名 / 数字 / 单位 / 数据集与产品名必须在原文里能找到对应
5. 原文太短或缺关键信息时，宁可返回更短的摘要，不要靠"地理常识"扩写（不要顺手补上"位于板块交界""属于亚热带季风气候"这类原文没有的解释）
6. 不要复述你"知道"的同类事件 — 只写这一篇原文实际写的东西；不得把往年同地台风的风速、同区地震的震级、同类灾害的灾情当作本次数据写进摘要
7. 严禁编造以下高风险事实，原文没有明确给出就一律不写：
   - 经纬度、坐标、震中位置、台站名、站点编号、高程与深度数值
   - 震级与烈度（不得把 4.5 级写成 5 级，不得自行换算震级标度）、风速、气压、降雨毫米数、水位与流量
   - 伤亡、失踪、转移安置、受灾人口等人数；倒塌与受损房屋、道路、农田等数量
   - 面积、长度、体积、时间跨度（流域面积、洪泛范围、冰川退缩距离、海岸线变化、里程、工期）
   - 地名归属：不得把某地"归到"原文未写明的县 / 市 / 省 / 国家，不得把外文地名自行对位成某个具体中文地名，不得对争议地区作归属判断（按原文口径写）
   - 出处边界：不得引用或暗示本条原文之外的任何目录记录、事件编号、发震时刻、应急响应等级或灾情说法。同一站点、同一时段、同一断裂带的另一篇报道不算出处——只有本条材料里出现过的机构与记录才能写，读者在本条页面上打不开的材料一律不要提
   - 数字出处：摘要与事件综述里出现的每一个时刻、震级、烈度、深度、坐标、距离、人数与面积数字，必须与本条材料（`articles.body_text` 与登记字段）里的同一个数字逐字相等；对不上就整句删除，不得改写成"数公里""约数十人""多处受灾"一类模糊表述——校验器执行这一条，删掉的句子不会以另一种说法回来。只有三家读数之差、明确写成"级次"的整数级量级、跨时区的同一次日期允许推算；不同来源各有出处的分歧数字必须各自带出处，不得合并成一个数
8. 单位与量级必须原样保留，不换算、不约整、不改写：7.2 级 / M7.2 / 10 公里 / km² / 万公顷 / mm / m³/s / °C 距平 / 万人 / 米 / 级 一律照抄；不要把"3.5 万平方公里"写成"数万平方公里"，不要把英里、华氏、英亩换成公里、摄氏、公顷，不要把 "9.1" 写成"约 9 级"；同时保留测定或发布口径（如"中国地震台网中心测定""美国地质调查局给出"），不同口径的数值不得混用或互相替换
9. 未核实的数字必须带标记：原文写明"初步""速报""暂定""估算""待核实""未经确认""preliminary""更新中"时，摘要里必须保留同样的限定词（如"初步测定 6.8 级，正式测定为 7.2 级"）；原文只给"截至发稿""数据仍在更新"时照抄该说法；不得把待核实数字写成确定值，也不得删掉限定词让数字显得更可靠
10. 时间锚定：原文用相对时间（本周 / 上月 / 5 月 / 昨天 / 近日 / 今年 / 灾后第三天）就照抄那个说法，绝不补全成具体年份；原文没明确写出年份，摘要里就不许出现年份。即便下方提供了【时间锚点】，那只供你理解时序，不要据此把相对时间换算成绝对年份写进摘要。事件本身的发生时刻（发震时刻、登陆时间、生效日期）与报道或发布时间冲突时，按原文区分写明，不要合并成一个。
11. 不得强化原文语气或范围："多项研究未发现"不能改成"没有研究"，"正在监测"不能改成"已经确认"，"可能影响局部地区"不能改成"将波及大范围"，"尚未收到伤亡报告"不能改成"无人员伤亡"或"灾情轻微"。
12. "独立"、"完全"、"首次"、"唯一"、"史上最大"等排他性与极值表述只有原文明确写出时才能保留。
