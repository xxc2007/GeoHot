# GEOHOT 重大更新：动态与交互验收（2026-10-24）

仅修改更新日志专题组件与置顶呈现，不涉及采集、数据库、回执、模型、部署、CDN 或本机网络。无新增依赖。

## 可见变化

- GEOHOT 墨青山脊以本地 Canvas 绘制。指针与触屏改变山形，方向键微调，Home 复位；暂停保留当前相位，重播恢复初始山形。最多 24 fps、像素比上限 1.5。离屏、后台与系统减少动态时不申请连续帧；卸载清理 observer、监听与 rAF。SSR 提供本地 SVG 保底，无 JS 时仍有山脊与完整五站文字。
- 五站从静态五列改为可点选的阶段说明，支持方向键、Home、End 与 roving tabindex。连接线使用本地 SVG/CSS 流动，后台或专题离屏暂停；减少动态模式禁用动画。
- 对比页签展示本轮已有测量：受控后备数据的首页 HTML gzip 54,210 → 20,027 B（约 -63.1%），以及首批 12 条 / 后续 40 条的加载方式。前后选择与分批演示均可操作。明确标注本地快照和交互示意，不把载荷体积当成服务端毫秒、线上性能或国内/国际测速。
- 最新且符合当前类型筛选的重大更新，完整置于主内容 h1 下、普通日期日志前。日期分组仍以全部匹配记录计数；重大更新不在日期列表重复。重大更新独占日期时，该日期 anchor 放在置顶容器；同日还有普通记录时保留在日期分组。较早的重大记录作为普通历史记录保留。
