# GEOHOT 2.0 线条字形调整（2026-10-24）

按站长提供的 AIHOT 截图及线上重大更新重新校准：左侧 GEOHOT、右侧大型 2.0、贯穿画面的细密横线、浅青底色。上游公开仓库不包含线上站点的 FeatureRelease 实现，因此本次按实际可见效果独立实现；不声称源码或逐像素完全相同。

原版用高斯函数生成山峰，无法形成版本数字。本次改为固定 2.0 向量字形的扫描线浮雕；轻微自主波动、流动短线与局部指针/触屏扰动，不再改变整座山峰。移除可见操作说明、暂停和重播按钮及失效 CSS。重大更新置顶、原有五站/对比交互保留。

验证一次：web typecheck、/geohot 生产构建、本地 fixture 浏览器 1440/390px、置顶/锚点/筛选/计数、实际动画像素变化、减少动态模式下触摸改变实际像素、键盘、离屏与后台停帧、无 JS fallback、无页面错误及横向溢出。未重复运行数据库/模型测试；CI 按仓库 required checks 执行。

动画只随 changelog 加载，无新依赖/字体/网络请求。整个 changelog JS gzip 7,944 B，CSS gzip 1,630 B。动画限 24fps、DPR 1.5，离屏/后台/减少动态时停止连续帧，组件卸载清理监听与观察器。
