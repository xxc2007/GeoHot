# 服务器管理、Magpie 接入与访问稳定性

按用户已确认的要求执行：保留现有后台视觉，系统菜单为服务器、运行、magpie、用量总览、模型、审计记录、设置。

1. 先定位 503：核对进程、内存压力、数据库、公开读取和 nginx 缓存；保持 R115、单一账本、未知回执和本机网络不变。当前已观察到内存/IO pressure 接近 98%，不能以扩大并发处理。
2. 后台新增服务器页：轻量读取系统指标、服务状态、更新时间及安全白名单配置；敏感凭据、完整进程参数、环境变量不可进入接口。
3. 后台新增 magpie 页：以管理员会话保护服务器侧反代；禁止公开 loopback 网关或把固定管理密钥写入网页。检查子路径资源及写操作来源校验。
4. 每 24 小时通过官方更新器检查版本，保留旧二进制并在健康检查失败时回滚；日志不含管理密钥。
5. 恢复本机迁移配置，保留迁移前和当前快照；避免覆盖用户新登录及两端竞争单次刷新令牌。按供应商分别验证可用性，不能把远程入口说成独立本机登录。
6. 修复页面并发读取和聚合热点；按相同网络条件与 AIHOT 对照。验证范围分开记录：本机、服务器直读、正式浏览器和地域探测。
7. 阶段验证一次，最后复用 CI 全套结果并做正式域名交互验收；提交 PR、合并部署，保留回滚与验收材料。
