# 国际非论文信源扩充：2026 年历史入口核验

核验日期：2026-10-10（Asia/Shanghai）。本轮只产生候选配置和证据；未修改 `industry/sources.json`，未接触生产数据库、服务器或任何写入接口。开始时从配置实数得到 294 个信源。

## 缺口与结果

现有配置大量覆盖地球科学期刊、欧美科研机构和自然灾害；人口、迁移、亚洲城市交通、非洲城市交通、拉美区域发展的一手机构消息更稀疏。本轮补充 5 个未登记的非论文信源。URL 和 ID 判重均通过，`unsupportedConfig` 五项均返回空数组。

| --- | --- | --- | --- | --- |
| web-unfpa-news | UNFPA 新闻 HTML | 12/12 | 人口普查、人口转变、亚洲/非洲/拉美社会空间 | T1：联合国机构自有官网的一手消息 |
| web-iom-news | IOM 新闻 HTML | 18/18 | 国际迁移、流离失所、边界通行、跨区域人口流动 | T1：联合国移民机构自有官网的一手消息 |
| web-adb-news | ADB 新闻发布 HTML | 10/10 | 亚洲交通、区域连通、城市发展与小岛国家 | T1：多边开发银行对自身项目的一手声明 |

| rss-itdp-news | ITDP RSS | 9/9 | 印度、印尼、巴西、墨西哥、非洲城市公共交通 | T2：非政府组织政策新闻和倡议，须保留立场和更严格筛选 |

以上等级是待登记的建议，依据是主体身份与内容来源关系，不代表内容自动入选。`first_party=true` 仅说明机构自己发布，不代表灾害数字已独立核实。ITDP 并非政府来源。ECLAC 配置限定本机构新闻/发布 URL，不把该网站聚合的外部媒体消息算作联合国一手报道。

机器可读交付为 `tooling/corpus/source-proposals-international-2026.json`。各 `proposals[].source` 是遵循本仓库配置键的可运行来源对象，证据和历史入口位于对象外；不要把整份报告 JSON 原样合并到行业配置中。全部关闭全文转载，按原站默认仅供摘要和原文链接。

分页回填建议：UNFPA 从 page=0 至 3；IOM 从 page=0 至 8；ADB 从 page=0 至 11；ECLAC 从 page=0 至 1；ITDP RSS 从 paged=1 至 5（第 5 页未核验）。按每条原发布日期过滤 2026-01-01 至 2026-10-10，必要时保留网站运营时区的完整当日窗口。该页数是本轮抽查得到的边界线索，正式回填应继续到发现窗口起点之前的日期，并检查分页重复、链接规范化、缺失日期和未来日期，不能把页码当稳定合同。

HTML 列表日期只有“日”的来源用 `publishedAtUtcOffset=+00:00` 保证跨机器一致；这属于日级归档规则，不是声明原文恰好午夜发布。UNFPA/ITDP 的原始时间含明确时区，保留原精度。ADB 列表的 HTML 有空的首个日期 span 和嵌套标题，所以配置以日期正则取可见真实日期，并精确选 `/news/` 英文链接。直接选择首个 span 会丢失日期，选择首个 a 会误中空的日文链接，本轮已规避。

## 筛选和出刊接续

这些机构会发布非地理的管理、人事、融资或一般卫生消息。接入后沿既有工作流进行 URL 判重、地理预筛、两次独立打分、中文标题和摘要、事件归组，不能用机构等级绕过筛选。优先保留能明确回答“发生在哪里、空间分布或跨区域关系如何变化”的材料。

历史新闻事实与机构归因分开。不要将模型总结或机构倡议写成本站编辑部立场；涉及灾害和人口数字时保存原文链接、发布日期、统计对象和时间范围。回填数据走同一材料管道，日报、周报和月报只消费已经完成筛选的公开发布层，不能从候选文件直接生成精选。

## 失败候选与验证边界

- Stats SA RSS `https://www.statssa.gov.za/?feed=rss2`：本机 Node fetch 失败；没有成功解析样本。
- IBGE 新闻 `https://agenciadenoticias.ibge.gov.br/en/agencia-news.html`：HTTP 403；没有成功解析样本。
- 世界银行交通博客猜测 RSS `https://blogs.worldbank.org/en/transport/rss.xml`：HTTP 404；没有登记。
- ADB 猜测 RSS `https://www.adb.org/news/rss.xml`：HTTP 404；改用实际可读的 HTML 发布列表。
- ECLAC 最初猜测 `.../list/press_release?page=1` 虽返回 200，但没有条目；通过官网导航确认真实入口 `.../list/cepal_pr` 并重新解析。HTTP 200 不能独立证明来源可用。

已验证：真实网络读取、日期/标题解析、配置键、候选 ID 和 URL 不重复、历史页面存在且能解析。未覆盖：全年逐条回填、全篇事实核查、生产服务器网络、生产数据库写入、模型筛选、出刊、前端显示和法律授权全文转载。
