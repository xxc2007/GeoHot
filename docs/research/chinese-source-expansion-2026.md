# 中文官方信源扩充与历史入口核验（2026-10-10）

本轮在 `industry/sources.json` 的 294 条登记记录基础上核对 URL 与 ID，提供 **6 个未登记、可由现有 web_list 采集器解析的中文官方入口**：5 个近期列表可启用，1 个低频统计公报保留为停用的历史资料入口。没有修改 `sources.json`，没有调用模型、数据库、付费抓取或生产接口。

候选配置：`tooling/corpus/source-proposals-chinese-2026.json`。复验命令：

```powershell
node tooling/corpus/verify-chinese-source-proposals-2026.mjs
```

该脚本先用 `assertSupportedConfig` 检查白名单，再检查登记重复，再通过项目自己的 `fetchWebList` 抓取与解析。2026-10-10 实跑退出码 0：6 个入口共 **113 条列表记录、113 条解析到日期**。这是可解析性证据，不代表已经入库、被筛为地理信息或刊入日报。页内日期只有日精度，不能当作小时级发布时间；默认 ISO 日期是 UTC 零点，国家数据局点号日期按声明的 +08:00 解析，与既有 `sources/dates.ts` 行为一致。

## 登记清单的覆盖缺口

原登记已包括国家统计局、中国科学院、地理资源所、自然资源部、水利部、生态环境部、应急管理部、发改委等部门；中国科学院科研列表和中文地理期刊覆盖较好，但没有国家数据局的公共数据政策发布入口，也没有地方统计局的人口/城市统计列表和京沪穗地方政务频道。

这些缺口与“国际期刊回填大多是英文、地方城市空间变动缺少中文一手入口”相关。新增入口可补数据政策、人口统计、城市更新、交通与区域治理，但京沪穗覆盖不代表全国地方覆盖。地方门户既有官方文件也有转载新闻，因此三个政务门户设 `first_party=false`，只有数据局和统计局的自身发布设为 true，全部 owner_entity_id 留空，避免捏造实体登记。相关性和重要性继续由现有预筛、两次独立评分、摘要和归组工作流判断；一般政务会议、招聘与纯消费促销不应因来源官方就直接公开。

## 历史地理与其它未接候选

中国社科院[历史研究院成果页](https://www.cass.cn/xueshuchengguo/xscg_lsyjy/)实际 200、25,237 字符，有“从考古资料看青藏高原丝绸之路的形成与历史影响”“海疆史研究”等相关标题；`index_1.shtml` 也实际 200。但列表没有逐篇发布日期，URL 日期不能直接冒充发表日期。未加入本轮可运行配置，后续需要配置并逐篇验证 detail 元数据日期，才能进入历史回填。同页“访埃见闻”的详情实际 200，只能证实详情可达，不能据此证明整栏日期完整。

其它实际失败/无解析记录：住房城乡建设部 `/xinwen/gzdt/index.html` 200、6,227 字符但空列表；国家文物局 `ncha.gov.cn`、中国考古网 `kgzg.cn`、`kaogu.cssn.cn` 本机 fetch failed；深圳门户 fetch failed；广州统计公报 403；北京统计猜测路径 404；中国社科院猜测的历史/考古学部路径 404；浙江统计年鉴 200 但静态列表无可解析条目。它们属于候选或需适配入口，不登记成已验证源，不以搜索结果缓存代替项目采集器实际可用性。

本轮交付不包含完整 2026 语料、不包含生产上线，也不构成全国中文地区/历史地理信息完全覆盖。建议优先完成上述 4 个可跨年边界的近期源历史分页计划，再把北京早期缺口、历史地理详情日期和更多省级人口公报拆成下一轮有证据的任务。
