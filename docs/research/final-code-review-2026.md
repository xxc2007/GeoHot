## 付费回执关键补丁的独立核对

`requestFor()` 同时构造真实 HTTP 请求与候选回执 identity，包含每个模型的 model、promptVersion、system/user hash、temperature、maxTokens（含 reasoning headroom）、json 与 extra。候选从当前 purpose 对应的真实配置池取得；显式池外模型或单模型切换不会偷偷恢复池外回答。

`paidRequest()` 在查询回执前按所有候选服务名的固定顺序取得事务预算锁，再按 id 取得回执行锁。logical key 包含 service：会竞争同一候选 key 的两个池选择，至少共享该服务锁，因此当前配置内的并发切换不能同时为同一步骤购买两次。received/completed 先恢复，无已收到回答时 pending/unknown 阻止另一个池成员购买。失败且确认未接收的步骤可以依法重试，仍使用相应服务预算。原模型健康统计仅使用 `origin='live'` 的已明确状态，不把正在请求的 pending 当作失败。

独立 `geohot_a18_test` 数据库中，`tests/receipt-pool-recovery.test.ts` 九项全部通过：预筛已成功但评分失败后的池切换恢复、unknown 拦截、stale pending 转 unknown、缺失旧候选凭据仍可复用其回执、并发 in-flight 保护、两次独立评分的 attemptTag 分离、候选参数变化拒绝错配、单模型切换边界、输入/提示词/JSON/重跑标签变化拒绝错配。所有请求仅发送至 localhost stub，没有使用生产模型或生产库。生产现有回执内容与真实服务状态由运维检查另行验证。

## 其他边界核对

- 新回填入口写入 material 与队列，不写 analyses.selected 或手工分值；筛选仍由既有分析、公开投影与成刊读取层决定。研究摘要只进入受限 raw provenance，原创正文提取路径及已有正文保护保留。
- 北京时间日报 08:00 截止、整周与整月已关闭窗口、unsettled 状态、补刊失败退出码及最终 refresh 分别有代码与既有回归覆盖。没有可刊材料的日子不会伪造报纸；最终补刊完整性要按真实队列/材料状态验收。
- 本轮新增采集与状态脚本不创建公开 DB 读取旁路。公开 site/v1/MCP/OG 路由继续调用 publication 读取层；移动端仍只请求 API。没有新增读者点击触发模型调用。
- 未发现受版本控制的私钥或真实 `.env`/`.data`。密钥模式检索命中少量原文 URL 中 `disk-`、`risk-` 的子串，经上下文核对属于误报。此项只是已扫描模式的静态检查，不能证明所有可能的凭据格式均不存在。
- 定时器使用 flock，日志与状态落在私有目录；服务限制内存/CPU，单轮有总时间截止和阶段超时。期刊 MAX_ITEMS 与新闻阶段固定 100 是分阶段上限，新闻加入后不能继续描述为整轮最多 100。
- 私有迁移包包含源文件、数据库、运行时、persistent 数据和配置，排除依赖与可再生成图片缓存；`.env` 仅置于私有 0600 外包中。可迁移结论须以其他检查 agent 的真实恢复演练及最终版备份为准。
- 移动修改局限于报头宽度、搜索触摸尺寸、横向当前分类可见性、搜索输入焦点保护与稳定周序号。静态审阅与前端测试不能代替生产手机浏览器验收。
