# 两支网站宣传片 · 制作基准

- 模式：自主创作，用户于 2026-10-08 明确选择；连续推进到制作、独立审查及三个 GitHub 仓库同步。
- 产品：个人介绍站与 GEOHOT；受众为首次访问个人主页的读者、网页设计与地理资讯读者。
- 输出：每站一支约 35 秒的中文横版宣传片，1920×1080 / 30fps / H.264 + AAC；同时保留 SFX-only 版、README 轻量版、封面、播放器和可重渲源码。
- 承诺：个人站“把想清楚的事做成可访问的地址”；GEOHOT“按空间显著性筛选地理资讯，每条留原文地址”。不宣称研究结果、灾害预测或未经验证的测试覆盖。
- 必须展示：个人站首屏、两个作品、做事方法、信念、联系入口；GEOHOT 精选、七分类、事件与原文证据、日报、主题/Agent 入口。
- 数据：个人站只用用户已公开的头像、文案与邮箱。GEOHOT 只采公开读者页面，截图冻结，标注拍摄日期，不把新闻截图当成最新播报；不访问后台或真实评论。为确保与当前生产读者界面一致，GEOHOT 从公网采集真实页面快照，个人站起本地服务器采集；录制后完全离线渲染。

## 需求与决策

|需求|实现|验证|

|参考仓库展示|醒目封面、原生视频、高清播放与源文件链接；主页按作品分别呈现|GitHub 渲染与播放检查|

## 参考片动效拆解

|手法|参考片实现|适配|
|---|---|---|
|品牌落字|左上 logo、大衬线居中、细线收束|各站 logo/名称；静止 ≥1 秒|
|首屏聚光|单页斜侧推进、抬升、两圈轮廓、归位|沿用参考原片整页 HeroShot，并借用 spotlight demo 的 rise/hover/reseat 时值，不重复创造第二个主角|
|功能段|时间轴、照片墙、昼夜匹配、地图、留言|替换为作品/步骤/信念与分类/事件/日报；每镜只讲一件事|
|结尾组装|截图组件飞入，字标在中央落定|各站截图作为外围证据、中央品牌与公开 URL；hold ≥1 秒|

## 视觉方向与动态基准

选定“网页作品册 / 地理新闻纸”：两片共享运动语法，分别继承自己的色板和排版。参考片与目标站已有明确品牌，跳过额外 styleframe，先出开场/功能/结尾真实 still 验证。能量低→中→中高→收束；小幅斜侧机位只用于首屏，密集列表正视。固定种子、无 handheld、无逐拍全画面震动。主标题字号 62–128，叙事字幕 64，辅助字 40，边缘安全区 ≥80px。

## 功能到镜头映射及分镜

采用约 72 拍、35 秒；切点根据选定音乐实际网格生成，不抄参考片绝对帧。

|镜头|拍区间|个人站|GEOHOT|主动作/声音|
|---|---|---|---|---|
|brand|0–6|熊鑫晨 / 个人介绍|GEOHOT / 地理热点|衬线逐字落定 + typewriter；hold|
|hero|6–17|真实首页|真实精选页|原片整页 HeroShot + spotlight 时值参考；推近→抬升→描边→归位；whoosh + sparkle + snap|
|features|17–28|两张真实作品卡|七分类与 GIS 真实资讯|真实截图卡片依次嵌入；row-embed；轻转场|
|detail|28–40|真实做事步骤|事件页综述与多来源|PageCam 正视沿内容推进，辅助编号/细线；marker|
|reading|40–52|中英双语页面匹配|真实日报页面|同构页面匹配 / 日报推读；transition|
|values|52–60|真实信念与联系入口|主题与 Agent 接入页|两个真实片段分栏、最后落定；轻转场|
|outro|60–72|个人站截图全家福 + URL|地理热点截图全家福 + URL|参考片 OutroShot 组装；riser→impact→sparkle；结尾 hold|

选中卡与变体：spotlight-hero-card / row-embed。读取 gallery/api/library.json、配方卡及准确 demos；PageCam 源自技能 assets/lib。原片 HeroShot/OutroShot 作为既有已验收参考实现，按目标产品重新蒙皮。功能页采用独立 PageCam 正视推进，结尾采用原片组装。

## 同步边界

源站业务页面保持原有信息结构，新增独立宣传片入口与 assets，不修改筛选、数据、后台或生产模型配置。GitHub 三仓库同步是本次授权范围；播放器会采用可公开访问且实际验证的地址，原生预览必须拿到真实上传返回链接，禁止伪造附件 ID。

## 制作放行

自主审查：每个必拍功能均有镜头；公开截图与源码一致；参考动效与目标 token 兼容；时值包含品牌和列表落定停留。阶段 0–3 放行，2026-10-08。

## 镜头卡适配记录

用户要求模仿的是南昌十五中原片，因此首屏遵循该原片的整页悬浮 HeroShot。spotlight-hero-card 卡与准确 demo 已审读，但只借用聚光、推进、抬升、两圈描边与归位的时值；没有使用 demo 的单卡槽位补丁与 34°侧机位，不声称完全复现该 Gallery 变体。row-embed 用真实网页元素坐标、背景槽位覆盖与卡片独立飞落嵌入；产品与字体 token 自主适配。

线上路由核验发现 /promo/ 为既有纪念册旧链接永久跳转入口；新播放器使用个人站已归属的 /assets/promo/ 与 /assets/promo/geohot/。既有纪念册迁移规则保持有效。
