# 精选的最低原始证据门禁

自动精选至少应有标题之外的原始摘要或已确认正文，或具有实际文本的原始社交帖子/引用帖子。模型生成的导读、译文和高分不能反过来证明输入充分。门禁不设任意字数下限，保留短地震和水文警报；它也不是事实准确性、独立来源数量或转载许可的判定器。

判断前解析 HTML、解码实体、移除脚本和链接包装，再归一化标点与空白。仅有标题、标题片段、重复标题、空实体和纯数字包装不构成额外证据。原始摘要仍由现有相关性、事实与写作检查负责，门禁不宣称任意一段非标题文字都有足够编辑价值。

证据不足时仅撤销自动精选资格，保留原始文章、分析结果和普通动态 eligibility。既有同步账本会发送 remove，后续恢复证据时发送 upsert，重复重建不额外发送相同变更。引用该文章的存版报刊和缓存仍须按现有重发布流程重新核验；单个投影变更不能证明全站存版已更新。

人工明确强制入选保持既有优先级，后台已有必填的操作理由可作为人工选择的记录；可选的推荐理由仍可为空。只有 selected=true 且保存了操作理由或既有推荐理由才豁免自动门禁。这保留操作者意图，不宣称任何操作理由都等于事实核验。人工设置不解除隔离、下架、语言和来源层级等其他公开规则。
